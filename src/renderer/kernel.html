为什么更新是安全的

  • 快照独立：每个版本是 core/snapshots/<version> 下的一棵完整目录，新版本先落到暂存目录，与当前内核互不覆盖。
  • 先冒烟后启用：新内核在随机端口以 token 鉴权启动，只有进程起来了且 HTTP 有响应，才会被提升为当前版本；在此之前旧内核一直在正常服务。
  • 失败自动清理：冒烟测试或校验失败时，暂存目录会被删除，配置中的当前版本指针保持不变，因此当前内核不受影响。
  • 数据不随内核走：profile、插件与会话位于 DSH_HOME，不在内核目录内，切换或回滚内核不会丢失插件与会话。
